# FIAR Practice prototype

A standalone, responsive browser prototype. No build tools or dependencies are required.

## Run locally
Open `index.html` in Chrome, Edge, Firefox, or Safari.

## Deploy free with GitHub Pages
1. Create a GitHub account (if needed) and a new public repository, e.g. `fiar-practice`.
2. Upload `index.html` to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages URL to appear. It will look like `https://YOUR-USERNAME.github.io/fiar-practice/`.

Alternative: drag the folder into Netlify Drop at https://app.netlify.com/drop (sign in first) to publish a static site.

## Important rules/board note
This is a first-pass practice prototype based on the publicly available Math Pentathlon Division II FIAR Tournament Highlights and a simplified, independently drawn 7x7 network. It is NOT an official Math Pentathlon product and is NOT tournament-accurate yet. In particular, the exact physical board topology, the precise central yellow-area geometry, and the full movement rules should be checked against the official board/manual before relying on it for tournament practice.

Official public highlights: https://www.mathpentath.org/wp-content/uploads/2026/01/Highlights-Division-2.pdf
Official FIAR product description: https://mathpentath.org/products/fiar-complete-game
